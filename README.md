# Fakhri Manager 3D (Flutter) — v0.2

لعبة محاكاة مدرب كرة قدم لأندرويد. واجهة عربية RTL + English.

## الحالة الصادقة
**لم يُشغَّل الكود في Flutter قبل التسليم** (لا يوجد Flutter في بيئة الإنشاء). قد تظهر أخطاء بناء بسيطة، أرسلها وسأصلحها.

### منفَّذ
شاشة البداية، مسيرة جديدة (8 أندية خيالية)، لوحة التحكم، الفريق (4 تشكيلات، 5 تكتيكات، جعل لاعب احتياطيًا)،
صفحة اللاعب، محاكاة مباريات (مشاهدة على ملعب 2D / محاكاة سريعة / أبرز الأحداث) بتعليق عربي وإحصائيات،
دوري ذهاب وإياب وهدافون ومواسم متعددة وتطور اللاعبين، سوق انتقالات (شراء بعروض، بيع، كشافة، عروض واردة)،
لياقة وإصابات، بريد، سجل مدرب، حفظ تلقائي بعد كل جولة + حفظ/تحميل يدوي.

### غير منفَّذ
ملعب 3D (الملعب 2D مبسّط وحركة الكرة تقريبية وليست محاكاة حقيقية لتمريرات اللاعبين)، تبديل أثناء المباراة،
القائد والركلات الثابتة، تفاوض على الراتب/العقد، إعارة، شاشة تدريب، كأس وبطولات قارية، مؤتمرات صحفية،
رضا الإدارة والجماهير، الإقالة.

## البناء
- ملف `pubspec.yaml` في الجذر، والكود في `lib/`.
- مجلد `android/` غير موجود. ملف `.github/workflows/build.yml` ينشئه تلقائيًا بالأمر
  `flutter create --platforms=android --org com.fakhri --project-name manager3d .`
  (معرّف التطبيق `com.fakhri.manager3d`) ثم يبني APK ويرفعه كـ artifact.
- محليًا: `flutter create --platforms=android --org com.fakhri --project-name manager3d .` ثم `flutter pub get` ثم `flutter build apk`.
